# اسکنر پروتکتیو پوت (بورس ایران)

هر چند دقیقه در ساعات بازار، همه‌ی پوت‌های بازار رو اسکن می‌کنه و برای استراتژی **«خرید سهم/صندوق + خرید پوت (حدضرر)»**
موقعیت‌های خوب رو با تحلیل کامل به کانال تلگرام می‌فرسته.

## منطق
قیمت‌ها از بهترین قیمت عرضه (ask) و با کارمزد. بدترین حالت تا سررسید (اعمال پوت در strike):

    worst = K·(1 − کارمزد اعمال) − [ S·(1 + کارمزد سهم) + P·(1 + کارمزد آپشن) ]

| هشدار | شرط پیش‌فرض |
|---|---|
| 🟢 سود تضمینی | `worst > 0`، حاشیه ≥ ۰٫۵٪ و حاشیه سالانه ≥ نرخ بهره (`OPT_RATE`) |
| 🟡 حدضرر ارزان | بیشترین ضرر ≤ ۱٪ (سود سهم بالا بازه) |

فیلتر ارزش معامله: پوزیشن قابل‌اجرا با حجم عرضه‌ی بهترین قیمت پوت و سهم ≥ ۱۰ میلیون تومان. پیام شامل: محاسبه‌ی کامل، سربه‌سر،
سناریو، IV/دلتا/تتا، مقایسه با wiv و HV، جریان پول حقیقی، ظرفیت اجرا و نکات ریسک.

## راه‌اندازی
1. ریپوی جدید بساز و این پروژه رو push کن.
2. **Settings → Secrets → Actions:**
   - `TELEGRAM_BOT_TOKEN` — توکن ربات
   - `OPTIONS_CHAT_ID` — کانال آپشن (ربات باید ادمین کانال باشه؛ مثل `@mychannel` یا `-100…`)
   - `GIST_ID` + `GIST_TOKEN` — (توصیه می‌شه) حافظه‌ی ضدتکرار روی Gist. بدون این دو از cache استفاده می‌شه.
   - اختیاری: `OPTIONS_API_URL`، `OPTIONS_API_HEADERS` (JSON)
3. تب Actions → *Option Scanner* → Run workflow برای تست.
4. برای دقت زمانی، زمان‌بند بیرونی بتونه `repository_dispatch` با نوع `run-options` بزنه؛ cron گیت‌هاب گاهی تأخیر دارد.

## تنظیمات (متغیر محیطی `OPT_*`)
| متغیر | پیش‌فرض | معنی |
|---|---|---|
| `OPT_MIN_LOCKED_MARGIN_PCT` | 0.5 | حداقل حاشیه 🟢 (٪) |
| `OPT_MIN_LOCKED_ANNUAL_PCT` | -1 (= نرخ بهره) | حداقل حاشیه سالانه 🟢؛ `0` یعنی هر سود تضمینی مثبتی (حتی زیر سود بانکی) |
| `OPT_MAX_LOSS_PCT` | 1 | بیشترین ضرر 🟡 (٪)؛ 0 = غیرفعال |
| `OPT_MIN_POSITION_VALUE` | 100000000 | حداقل ارزش پوزیشن (ریال) |
| `OPT_RATE` | 0.42 | نرخ بهره‌ی بدون ریسک سالانه (هزینه‌ی فرصت، آستانه‌ی خودکار 🟢، بلک-شولز) |
| `OPT_STOCK_BUY_FEE` / `OPT_SELL_FEE` / `OPT_EXERCISE_FEE` | -1 (خودکار) | کارمزد خرید/فروش بازاری/اعمال پایه؛ -1 = از جدول زیر به‌ازای نوع پایه |
| `OPT_OPTION_BUY_FEE` | 0.00103 | کارمزد معامله‌ی اختیار |
| `OPT_COOLDOWN_HOURS` / `OPT_IMPROVE_PP` | 3 / 0.25 | تکرار هشدار هر پوت: بعد از این ساعت یا بهبود این‌قدر درصدواحدی |
| `OPT_MAX_ALERTS` | 8 | سقف پیام در هر اجرا |
| `OPT_MAX_STALE_MIN` | 20 | قدیمی‌تر از این (دقیقه) = بازار بسته/تعطیل، اجرا رد می‌شه |

اعمال سهام مالیات داره و اعمال ETF نداره.
اگه کارگزاری‌ت فرق داره با `OPT_*` override کن. اگه پایه از بالای strike بره، فروش بازاری (کارمزد فروش) و در غیر این صورت اعمال حساب می‌شه.

## محدودیت‌ها
- فقط حجم بهترین قیمت ask (سطح اول سفارش‌ها) سنجیده می‌شه؛ اول پوت رو بگیر بعد سهم.
- اروپایی: اعمال فقط در سررسید؛ پول تا اون موقع بسته می‌مونه (هزینه‌ی فرصت تو پیام هست).
- کارمزدها تخمینی‌ان. این ابزار توصیه‌ی سرمایه‌گذاری نیست.
